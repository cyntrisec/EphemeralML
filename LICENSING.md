# Licensing Posture

Cyntrisec's open trust surface is Apache-2.0 unless a file says otherwise.

This includes:

- AIR v1 specification materials, CDDL schemas, golden vectors, and interop fixtures.
- Reference verification code and verifier CLI binaries built from this repository.
- Local development, demo, and integration examples intended to help third parties verify receipts.

The goal is simple: customers, auditors, vendors, and researchers must be able to inspect, run, and adapt the receipt verification path without copyleft or source-available production-license friction.

Hosted services, managed deployments, premium support, marketplace images, and commercial control-plane features may be offered under separate commercial terms. Those terms must not be required to independently verify an AIR receipt with the public reference verifier.

If a subdirectory, dependency, bundled third-party artifact, or generated binary carries a different license, that narrower notice controls for that component.
